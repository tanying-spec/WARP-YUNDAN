# 安全与回滚

## 默认隔离

WARP-YUNDAN 不替换系统默认路由。独立路由表 `51889` 只匹配显式绑定 `wywarp` 的套接字，因此 SSH、监控和系统更新默认继续使用原生网络。

## 代理接入

接入只修改代理的 direct 出站：

- 原始配置保存到 root-only 时间戳目录。
- 写入前执行代理核心原生配置检查。
- 使用原子替换，随后重启并验证实际代理流量。
- 新增的诊断 SOCKS 入口只监听 `127.0.0.1`，使用随机密码。
- 撤销时逐字节恢复原配置，包括注释和原有凭据。

YAML 正式接入期间会被重新序列化，因此接入后的活动文件不保留注释；撤销后原始字节恢复。

## 防出口泄漏

代理套接字使用专用 fwmark 和路由表 `51890`。表内保留 prohibit 默认路由：如果 `wywarp` 消失，已标记流量失败，而不是回落到原生公网出口。

`hybrid` 只标记 IPv4 direct 出站；原生 IPv6 不受该阻断规则影响。`all` 标记 IPv4 和 IPv6。

## 冲突保护

安装和启动会拒绝同名接口、路由表、规则优先级冲突，以及其他 WireGuard 接口复用相同 WARP 公钥。脚本不会自动停止或删除检测到的旧服务。

代理接入还会拒绝已有路由标记、接口绑定、远端链、透明代理，以及操作中途被外部修改的配置文件。

## 私密数据

以下内容不得提交到 GitHub 或公开日志：

- `/etc/warp-yundan/wgcf-account.toml`
- WireGuard PrivateKey
- 代理 UUID、密码和订阅内容
- `/etc/warp-yundan` 内完整备份或日志
